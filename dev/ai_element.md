AI에게 일을 시키는 방법, AI가 일하는 환경을 만드는 방법, AI 가 작업을 연결하는 방법 등 서로다른 영역을 설명하고 있어요.

# 1. AI 모델(AI Model)

> 생각하고 판단하는 두뇌

대량의 데이터를 학습해서 패턴을 익히고, 새로운 입력을 받았을 때 결과를 만들어 내는 시스템이에요.
대표적으로 GPT, Claude, Gemini 모델이 있어요.

# 2. AI 에이전트(Agent)

> 목표를 받고 스스로 작업을 진행하는 일꾼

에이전트의 큰 특징은 스스로 다음 행동을 결정하고, 실행할 수 있다는 점이에요. 
일반적으로 AI에게 궁금한 것들을 물어보고 답변을 받잖아요. 반면 에이전트에게는 목표를 주어야 해요. 그럼 에이전트는 그 목표를 달성하기 위해 필요한 작업들을 계획하고 실행해요.

일반 적인 AI에게 요청
"이 코드에서 문제가 있는 부분을 찾아줘." -> 코드를 분석하고 문제점을 알려줍니다. 그럼 그 문제를 해결하라고 또 요청해야 겠죠.

에이전트에게 요청
"이 프로젝트에서 메모리 누수 문제를 찾아서 해결해줘" -> 프로젝트를 탐색하고, 분석해서, 코드를 수정하고, 결과까지 확인할 수 있습니다. 에이전트에 어느범위까지 실행할 수 있는지 권한을 주느냐에 따라 결과가 달라져요.

# 3. 프롬프트 엔지니어링(Prompt Engineering)

> AI 에게 원하는 결과를 얻기위해 질문이나 지시문(Prompt)을 효과적으로 작성하는 기술

예를 들어 AI에게 다음과 같이 요청한다고 해볼게요.

일반적인 프롬프트
"Swift 코드를 리팩토링해 줘."

구체적인 프롬프트
"이 Swift 코드를 리팩토링해 줘.
- 기존 기능은 유지해 줘.
- 중복 코드를 제거해 줘.
- 메모리 관리 측면에서 문제가 없는지 확인해 줘.
- 변경한 이유를 설명해 줘."

두 요청 모두 같은 작업을 요구하지만, 두 번째 요청은 목표와 조건이 더 명확해요.

이처럼 프롬프트를 어떻게 작성해야 AI가 원하는 방향으로 작업할지 고민하는 것이 프롬프트 엔지니어링이에요.

# 4. 컨텍스트 엔지니어링(Context Engineering)

> AI 에게 필요한 정보를 잘 구성해서 제공하는 기술

AI가 작업을 제대로 수행할 수 있도록 필요한 정보(Context)를 수집하고 구성해서 제공하는 기술이에요.

AI 에게 리팩토링을 요청하더라도 AI가 프로젝트 구조를 모르면 적절한 코드를 작성하기 어려울 수 있어요. 이때 개발환경, 아키텍처, 프로젝트 규칙, 참고 자료를 같이 제공하는 거예요. 이런 정보를 AI가 참고할 수 있도록 구성하면, 프로젝트에 상황에 맞는 결과물을 만들 가능성이 높아져요.

# 5. 하네스(Harness)

> AI가 제대로 일할 수 있도록 만들어 주는 실행 환경

Hareness는 원래 장비를 고정하는 장치라는 의미가 있어요. AI분야에서는 AI 에이전트가 안정적으로 작업할 수 있도록 주변 환경과 규칙을 구성하는 것을 의미해요.
