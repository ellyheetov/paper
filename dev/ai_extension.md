## Second Brain

> 머릿속 지식을 밖에 저장해두고 필요할 때 꺼내 쓰는 개인 지식 시스템

사람은 모든 정보를 기억할 수 없잖아요. 그래서 기억해야 할 정보나 나중에 활용할 지식을 외부 공간에 정리하고, 필요할 때 다시 꺼내 쓸 수 있도록 만드는 거예요. 읽은 글, 메모, 아이디어를 한곳에 모아두고 다시 활용하는거죠. 이 블로그도 공부한 내용을 기록해두는 것으로 Second Brain이에요.

전에는 모으고 정리하는 일을 사람이 다 했다면, 이제는 AI가 많은 부분을 맡아요. 단순히 정보를 저장하는 데 그치지 않고, AI가 저장된 지식을 검색하고 연결해서 활용할 수 있게 된거예요.

## AI Native

> 처음부터 AI와 함께 일한다는 전제로 일하는 방식을 설계하는 것

AI를 기존 업무에 단순히 추가하는 게 아니라, 처음부터 AI를 활용하는 것을 전제로 업무와 시스템을 설계하는 접근 방식이에요.

| 구분 | AI-enabled | AI Native |
| :-- | :-- | :-- |
| AI의 역할 | 필요할 때 쓰는 도구 | 함께 일하는 동료 |
| 사람의 역할 | 직접 작업 | 목표 설정, 검토, 판단 |
| 예시 | 코드를 짠 뒤 AI에게 리뷰 요청 | 요구사항을 주면 AI가 구현·테스트하고 사람은 검토 |

사람의 일이 직접 만드는 것에서, 무엇을 시킬지 정하고(Workflow) 결과를 확인하는(Evaluation) 것으로 옮겨가요.

## 정리

Second Brain은 **아는 방식**을, AI Native는 **일하는 방식**을 바꿔요. 둘 다 반복적인 일은 AI에게 맡기고, 사람은 방향을 정하고 판단하는 데 집중한다는 점에서 같아요.
