SwiftUI @State와 @Binding 정리

2026년 10월 30일 · 약 2분

SwiftUI에서 화면은 상태의 함수다. 상태가 바뀌면 뷰가 다시 그려지는데, 그 상태를 누가 소유하는지를 헷갈리기 시작하면 값이 엉뚱한 곳에서 바뀌거나 화면이 갱신되지 않는 문제가 생긴다.

@State: 뷰가 직접 소유하는 상태​

struct CounterView: View {
    @State private var count = 0

    var body: some View {
        Button("탭 \(count)회") { count += 1 }
    }
}
  • 뷰 안에서만 쓰는 단순한 값 타입 상태에 쓴다.
  • private으로 선언해서 바깥에서 초기값을 주입하지 않도록 한다.

@Binding: 부모의 상태를 빌려 쓰기​

struct ToggleRow: View {
    @Binding var isOn: Bool

    var body: some View {
        Toggle("알림", isOn: $isOn)
    }
}

struct SettingsView: View {
    @State private var notificationsOn = true

    var body: some View {
        ToggleRow(isOn: $notificationsOn)
    }
}

ToggleRow는 값을 직접 갖지 않고, 부모가 가진 notificationsOn에 대한 참조만 받는다. 토글을 움직이면 부모의 상태가 바뀌고, 부모와 자식이 함께 다시 그려진다.

한눈에 비교​

프로퍼티 래퍼소유자언제 쓰나
@State현재 뷰이 뷰만 쓰는 상태
@Binding부모 뷰부모 상태를 읽고 바꿔야 할 때

상태는 한 곳에서만 소유하고, 나머지는 빌려 쓴다.

  • @State: 뷰가 직접 소유하는 상태
  • @Binding: 부모의 상태를 빌려 쓰기
